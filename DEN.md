# The den: unofficial archive of imfebu.com

Folded in from the private repo `febu-host` (2026-10-15). Its history stays there.

Static copy of the imfebu.com front end **as of its 2026-08-14 build**, with the archived scripture. Not affiliated with febu. The community, jobs and the visitor counter run on a free Supabase project (`febu-host`; schema and seed in the febu repo, `scripts/supabase/`). The AI surfaces (ai/ii chats, graduation, rent, review, $VOID earning) and the ascii market are not wired.

- `index.html` + `assets/index-C4UKkDq2.js`: the 08-14 bundle (original sha256 starts `f33a597a`), **patched**: it talks to the `febu-host` Supabase project (publishable key, RLS protects the data) instead of febu's dead one; the "30+ $VOID" community gate is removed (feed and chat are open to read, posting needs the email sign-in box added to the room); the home link bar is full-width `gb-btn` buttons under "welcome to my den". Regenerate with `python scripts/patch_den_bundle.py` in the febu repo (reads the untouched `captures/imfebu_bundle_20260814.js`; each edit asserts it matches once).
- `assets/index-reconstructed.css`: **not the original**. The 08-14 stylesheet was never archived; this is Tailwind regenerated from the bundle plus hand-written `.retro-*` / `.gb-*` rules, in blue and grey.
- `assets/shim.js`: a thin layer in front of the bundle's Supabase calls. `scripture_pages` is served from `assets/scripture.json` (164 pages, 8 books, last page 2026-09-18); the AI tables answer empty and the edge functions answer 503 "not wired"; everything else (sign-in, community, jobs, storage, realtime, the counter) goes to the real project. If the project is unreachable, community reads and the counter fall back to `assets/community.json` (693 posts, 3,465 comments, 1,480 chat lines, captured 2026-07-15) and the last archived counter reading (32,817, 2026-09-23).
- `scripture.html`: plain-text reader of the same 164 pages. `members.html`: the Assembly's members.

## Backend (Supabase, free)
Project `febu-host`, ref `tytebptpuiiemuxlaeab`. Schema, RLS, rate limits, storage and realtime: `scripts/supabase/01_schema.sql` in the febu repo. The old posts, comments, chat lines and jobs, with a generated display name for every old user id: `02_seed.sql` (regenerate with `scripts/build_supabase_seed.py`, which reads the deployed `assets/community.json`). The key in the bundle is the publishable one: public by design, RLS decides who can write. "Confirm email" is off (Authentication, Sign In / Providers) because the free built-in mailer only reaches org members: sign-up signs the person straight in, and the app sends no email at all, so a lost password cannot be reset. Turn it back on only after setting up custom SMTP. Free projects pause after about a week idle; a Vercel cron (`api/keepalive.js`, daily) reads one row.
